## Goal

JS/TS users see fallow's findings next to slopr's in every format.

## Scope

- `fallow.rs`: run the configured commands (behavior step 4, with the format the spike chose), map results (step 6 and Run details), and handle fallow exit codes (step 8).
- `main.rs`: run fallow on its own thread in parallel with native rules. Merge before suppressions.
- `report/json.rs`: a real `tools` entry. `report/sarif.rs`: build the fallow run from the mapped findings (step 7).
- Extend the fake fallow: `$FAKE_FALLOW_DIR/<command>.json` is printed for each command. Add canned JSON files built from the spike's real output.
- Tests: `fallow_run_findings_in_human`, `fallow_run_sarif_fallow_run`, `fallow_run_json_tools_ok`, `fallow_run_exit_2_is_tool_failure` (slopr exits 3), `fallow_run_multi_location_split`, `fallow_run_paths_filter`.

## Out of scope

- `fallow audit`, which is V01.
- The real-fallow contract test, which is F03.

## Acceptance criteria

- The six tests pass.
