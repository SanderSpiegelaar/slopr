## Goal

Prove v0 is done by the roadmap's own terms.

## Scope

- `tests/rules.rs`: `catalog_v0_rules_registered`. It reads `docs/reference/rules.md` from `CARGO_MANIFEST_DIR`, takes every row whose Decision cell says `v0`, and asserts that `slopr rules` lists the rule and that `tests/fixtures/rules/<id>/` has at least one `bad*` and one `good*` file.
- `scripts/fp_corpus.py` per the FP corpus section.
- Run the corpus. Any default-on rule above 1.0 gets `default_on: false` in its module, and the PR says why.
- Add `## FP corpus results` to `testing.md`: the date, the slopr commit, the table, and any rule turned off.
- Run the contract test against fallow 3.42.0 (`F03`'s verify) and paste the result in the PR.

## Out of scope

- Tuning a rule to pass the corpus. Turn it off and file the tuning as a follow-up.

## Acceptance criteria

- `catalog_v0_rules_registered` passes.
- `fp_corpus.py --check` exits 0.
- The contract test passes against fallow 3.42.0.
