## Goal

slopr can be published under `MIT OR Apache-2.0` with correct notices for everything it ported.

## Scope

- Add the standard `LICENSE-MIT` and `LICENSE-APACHE` texts, with copyright holder "slopr contributors".
- Set `license`, `description` and `repository` (leave `repository` out if no remote exists) in `Cargo.toml`.
- Check that every provenance comment in `src/rules/phrases.rs` names a repo that has a section in `THIRD_PARTY_NOTICES.md`. Add any that are missing.

## Out of scope

- Renaming slopr, which the user decides before publishing.
- Publishing to crates.io.

## Acceptance criteria

- The verify command passes, and the notice check finds no missing repo.
