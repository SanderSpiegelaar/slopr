## Goal

Python, Rust and Go get the complexity limits fallow gives JS/TS.

## Scope

- `config.rs`: add the `function_max_*` and `file_max_lines` fields and keys.
- `complexity.rs`: both rules per the metrics section. File-size fixtures use a `slopr.toml` with a low `max_lines` so the fixture stays small.
- Unit tests in `complexity.rs` for each metric on a small snippet per language, compared with values worked out by hand.
- Fixtures with `expect:` markers in every language the rule covers, plus `good.*` files holding the near misses named in its coverage row.

## Out of scope

- Other v1 rules.
- Changing tests/snapshots. If a repos snapshot changes, stop and report it.

## Acceptance criteria

- `cargo test --test rules` passes.
