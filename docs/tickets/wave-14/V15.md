## Goal

Coding agents and pre-commit users run slopr the right way without reading the docs.

## Scope

- `skill/SKILL.md` with frontmatter `name: slopr` and a one-line `description`. The body says what the agents bullet in cli.md says, and nothing more.
- `slopr skill` prints it, embedded with `include_str!`.
- `.pre-commit-hooks.yaml`: one hook, `id: slopr`, `entry: slopr check --staged`, `language: system`, `pass_filenames: false`.
- Test: `skill_prints_skill_md` (byte-equal to the file).

## Out of scope

- An MCP server.

## Acceptance criteria

- The test passes, and `pre-commit try-repo .` works in a scratch repo (paste the output in the PR).
