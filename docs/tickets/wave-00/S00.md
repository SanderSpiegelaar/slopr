## Goal

Find out whether the grammar crates build with tree-sitter 0.27, and whether fallow's SARIF carries everything slopr needs. Every fallow ticket waits on this answer.

## Scope

- In a scratch crate outside the repo, depend on tree-sitter 0.27.2 and the four grammar crates at the versions in `dependencies.md`. Parse one file per language via `parser.set_language(&<crate>::LANGUAGE.into())` (for TypeScript, both `LANGUAGE_TYPESCRIPT` and `LANGUAGE_TSX`).
- Install `fallow@3.42.0` from npm. Build a scratch TS repo with a `package.json` and one planted issue each: unused export, unlisted dependency, duplicated block, a function over the cognitive limit, a circular import.
- Run `fallow dead-code`, `fallow dupes` and `fallow health` with `--format sarif --quiet`, then bare `fallow --format json`. Time each with `hyperfine` or `time`, three runs each.
- Also run `fallow schema` and `fallow audit --base HEAD~1 --format sarif --quiet`, and record their output shape.
- Add `## Phase 0 findings` to `fallow.md`: per planted issue, whether SARIF and JSON carry it and with which locations; the wall times; the shape of `fallow schema` output; the decision (keep SARIF, or switch step 4 to the JSON envelope); and the exact versions used.
- Add one line under the table in `dependencies.md` giving the grammar build result, with any version that had to change.

## Out of scope

- Any code committed to this repo.
- Mapping fallow output to `Finding`, which `F02` does.

## Acceptance criteria

- The section answers every question in fallow.md's spike paragraph.
- If a grammar crate fails to build, the line in `dependencies.md` names a working version or says that none exists.
- `python3 scripts/check-tickets.py` passes.
