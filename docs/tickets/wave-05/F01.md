## Goal

When a project needs fallow and it is missing or the wrong version, slopr stops at once with an install hint and exit 3.

## Scope

- `fallow.rs`: enablement (behavior step 1 and Run details), lookup order (step 2), version check with `semver` (step 3), and the exact error text: `slopr: fallow <found or "not found"> does not satisfy <range>. Install it with: npm install -D fallow@^3.42 (or cargo install fallow-cli --version ^3.42). Use --fallow off to skip.`
- `main.rs`: `--fallow auto|on|off` and `--fallow-bin <PATH>`, overriding `[fallow].enabled` and `bin`. The check runs before the walk.
- `tests/fixtures/fake-fallow/fallow`: an executable sh script that prints `fallow $FAKE_FALLOW_VERSION` (default `3.42.0`) for `--version`.
- `tests/fixtures/repos/js-min/`: `package.json` plus one `.js` file.
- Tests: `fallow_check_missing_exits_3`, `fallow_check_out_of_range_exits_3`, `fallow_check_in_range_passes`, `fallow_check_off_skips`, `fallow_check_auto_without_package_json_skips`, `fallow_check_bin_flag_wins`.

## Out of scope

- Running fallow commands, which is F02.

## Acceptance criteria

- The six tests pass, with the error text matched exactly.
