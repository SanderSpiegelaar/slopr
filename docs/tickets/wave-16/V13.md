## Goal

In diff mode, slopr warns on big changes with no tests and on oversized changes.

## Scope

- `config.rs`: add `pr_min_added_lines`, `pr_max_added_lines`, `pr_max_files`.
- `pr.rs`: both rules as `Check::Diff` per Diff mode.
- `tests/pr.rs` (temp git repos): `pr_no_tests_fires`, `pr_no_tests_quiet_when_test_changed`, `pr_oversized_lines`, `pr_oversized_files`, `pr_rules_silent_without_diff_mode`.

## Out of scope

- Other v1 rules.

## Acceptance criteria

- The five tests pass.
