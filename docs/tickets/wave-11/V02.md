## Goal

A team can adopt slopr on an existing codebase and fail only on new findings.

## Scope

- `suppress.rs`: read and write the baseline format.
- `main.rs`: `slopr baseline save <FILE>`, `check --baseline <FILE>`.
- Tests: `baseline_save_then_check_is_clean`, `baseline_survives_line_shift`, `baseline_new_finding_reported`, `baseline_missing_file_exits_2`, `baseline_file_is_sorted`.

## Out of scope

- Pruning stale entries.

## Acceptance criteria

- The five tests pass.
