## Goal

A fallow release that breaks slopr's mapping fails CI within a week.

## Scope

- `tests/fixtures/repos/ts-app/`: the planted-issue repo from the spike (unused export, unlisted dependency, duplicated block, a function over the cognitive limit, circular import).
- `tests/fallow_contract.rs`: `contract_planted_issues_reported`. It returns early with a printed skip notice when `FALLOW_BIN` is unset. Otherwise it runs `slopr check --format json --fallow on --fallow-bin $FALLOW_BIN` on ts-app and asserts the five matching `fallow/*` rule IDs (exact IDs from the spike) appear.
- `ci.yml`: the `fallow-contract` job and the weekly schedule from the CI section.

## Out of scope

- Snapshotting fallow output, which changes between versions.

## Acceptance criteria

- With fallow 3.42.0 on PATH, the verify command passes.
- With `FALLOW_BIN` unset, `cargo test` still passes.
