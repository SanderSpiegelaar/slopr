## Goal

Python, Rust and Go get copy-paste detection.

## Scope

- `config.rs`: add `dup_min_tokens` and `dup_min_lines`.
- `dup.rs`: `dup/exact-block` as `Check::Project` per the metrics section.
- Fixtures use the `bad/` and `good/` subdir layout from V04, with two files per language sharing a block. `good/` holds a renamed-but-same-shape block below the token threshold.
- Fixtures with `expect:` markers in every language the rule covers, plus `good.*` files holding the near misses named in its coverage row.

## Out of scope

- Other v1 rules.
- Changing tests/snapshots. If a repos snapshot changes, stop and report it.

## Acceptance criteria

- `cargo test --test rules` passes.
