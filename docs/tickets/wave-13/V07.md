## Goal

slopr flags lint and type-check suppressions that give no reason.

## Scope

- `suppression.rs`: `suppress/unexplained` per v1 language coverage. Rust `#[allow]` is an attribute node, not a comment, so match it from the tree.
- Fixtures with `expect:` markers in every language the rule covers, plus `good.*` files holding the near misses named in its coverage row.

## Out of scope

- Other v1 rules.
- Changing tests/snapshots. If a repos snapshot changes, stop and report it.

## Acceptance criteria

- `cargo test --test rules` passes.
