## Goal

slopr flags comments that restate code, narrate history, or read like model output.

## Scope

- `phrases.rs`: port the changelog and AI vocabulary lists with provenance comments.
- `config.rs`: add `vocab_min_distinct` to `RuleSettings` and accept its key.
- `comments.rs`: the three rules per v1 language coverage. `comment/obvious` is `default_on: false`.
- Fixtures in TS, PY, RS, GO for each rule. For `comment/obvious`, put a `slopr.toml` in the fixture dir that sets it to `warn`.

## Out of scope

- Changing tests/snapshots. If a repos snapshot changes, stop and report it.

## Acceptance criteria

- `cargo test --test rules` passes.
