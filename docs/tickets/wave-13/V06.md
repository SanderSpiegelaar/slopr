## Goal

slopr flags handlers that hide the error they caught, and error messages that say nothing.

## Scope

- `errors.rs`: the three rules per v1 language coverage. The vague-message regex is slopr's own and lives in `errors.rs`, not `phrases.rs`.
- Fixtures with `expect:` markers in every language the rule covers, plus `good.*` files holding the near misses named in its coverage row.

## Out of scope

- Other v1 rules.
- Changing tests/snapshots. If a repos snapshot changes, stop and report it.

## Acceptance criteria

- `cargo test --test rules` passes.
