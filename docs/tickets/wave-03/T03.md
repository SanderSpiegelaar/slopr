## Goal

CI and agents get machine-readable results and a configurable failure gate.

## Scope

- `--format human|json|sarif`, `--max-severity-exit info|warn|error`.
- `report/json.rs` and `report/sarif.rs` per Output formats, using `serde_json` structs (no SARIF crate). The fallow `tools` entry is always `{"name": "fallow", "version": null, "status": "skipped"}` until F02.
- `slopr rules`: one line per native rule, sorted by id, `<id> <default severity> <on|off> <summary>`.
- Tests: `output_json_snapshot`, `output_sarif_snapshot`, `output_sarif_required_fields` (the SARIF checks list), `output_gate_warn_fails_on_warn`, `output_gate_default_passes_warn`, `output_usage_error_exits_2`, `output_rules_lists_native`, `output_json_deterministic` (two runs, byte-equal).

## Out of scope

- The fallow SARIF run, which is F02.
- `slopr rules --all`, which is V14.

## Acceptance criteria

- The eight tests pass.
- Exit codes 0, 1 and 2 behave as the Exit gate section says.
