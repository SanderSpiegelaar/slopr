## Goal

Go projects get the same v0 checks as the other languages.

## Scope

- Add `tree-sitter-go` at the version in `dependencies.md`. Add `Lang::Go`, the `.go` mapping, and Go node kinds for `comments()` (`comment`) and `strings()` (`interpreted_string_literal`, `raw_string_literal`).
- Extend the v0 rules per Go coverage, adding `Lang::Go` to their `langs`.
- Add `bad.go` and `good.go` (or `*_test.go`) fixtures to every rule Go joins.

## Out of scope

- v1 rules on Go. Their own tickets cover it.

## Acceptance criteria

- `cargo test --test rules` passes with the Go fixtures.
