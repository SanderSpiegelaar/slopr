## Goal

In CI and pre-commit, slopr reports only findings on lines the change touched.

## Scope

- `diff.rs`: run git per the Diff mode section, parse `--unified=0` hunks into `Diff { files: Vec<ChangedFile { path, added: Vec<RangeInclusive<u32>>, untracked: bool }> }`.
- `main.rs`: `--changed-since <REF>`, `--staged`, restrict the walk to changed files, filter findings by span intersection, keep file-level findings.
- `fallow.rs`: in diff mode, run `fallow audit --base <base>` in place of the full-scan commands.
- Tests build temp git repos with `std::process::Command` and `git`: `diff_changed_since_filters_lines`, `diff_untracked_file_fully_changed`, `diff_deleted_lines_ignored`, `diff_rename_uses_new_path`, `diff_staged_only_index`, `diff_both_flags_exit_2`, `diff_outside_git_exit_2`, `diff_fallow_audit_used` (fake fallow records its argv).

- `pr/*` rules (V13).
